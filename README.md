# Studio: an AI Roblox game studio on Claude Code

The owner is the marketer and approves everything at the human gates. Everything else is done by
Claude Code subagents (see `CLAUDE.md`).

1. Setup on your Mac: `docs/setup.md`, then `./scripts/doctor.sh`, then `/toolcheck` in Claude Code.
2. `/new-game <idea>`, then APPROVE the GDD.
3. `/sprint` (repeat), `/playtest`, `/launch`, then you publish. `/status` any time.
