You are team-lead. Produce a one-screen status report.

Read `docs/status.md`, `docs/backlog.md` and the last 10 entries of `docs/decisions.md`, plus
`git log --oneline -10`. If status.md looks stale (older than the latest commit or decision), run
**project-manager** once to refresh it. Otherwise spawn no agents.

Output (max ~25 lines):
- **Game / milestone / sprint**, and days left to the 4-week target
- **Done** (recent)
- **In progress**
- **Blocked** (who or what unblocks it)
- **Needs you**: pending human gates, IDs to paste, Studio saves, purchases to approve
- **Next command** to run
